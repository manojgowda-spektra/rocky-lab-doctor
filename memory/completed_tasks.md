## Purpose of This Document

A chronological log of all completed work. This document:
- Prevents re-implementing work that already exists
- Provides an accurate history of what was built and when
- Allows any session to understand the progression of the project
- Supports audit, debugging, and onboarding

**Rule:** Every completed task, no matter how small, gets an entry. Entries are never deleted.

---

## Log Format

```markdown
### [Date] — [Task Name]
- **Type:** Feature / Bug Fix / Refactor / Research / Documentation / Infrastructure
- **Requirement:** [REQ-ID or "N/A" or "Exploratory"]
- **ADR:** [ADR-NNN if a decision was made, or "None"]
- **Duration:** [Approximate time]
- **What was done:** [1-3 sentences describing the work]
- **Files created:** [List]
- **Files modified:** [List]
- **Files deleted:** [List]
- **Tests added:** [Yes/No — brief description]
- **Known limitations:** [Any shortcuts taken or work deferred]
- **Completed by:** [Name / AI Session]
```
