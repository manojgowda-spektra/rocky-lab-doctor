The five gates — enforced in code (action/amnesty.js), not policy
  1. Fleet-confirmed — an OPEN false-fail case must exist in the reliability ledger. No single-learner judgment ever triggers a write.
  2. Regression-only — the monitor must show a sweep where this validator was working. A born-broken check is never amnestied; nothing was taken away.
  3. State-proven — each learner's own observed state must match the expected state. Missing evidence or wrong work is excluded, with the reason shown.
  4. Human-gated — the draft never self-executes. Execution refuses without a named authorizer (try it below with the box empty).
  5. Reversion-guarded — after the fix ships, every amnestied verdict is re-checked. One contradiction halts the pipeline. Target: zero.
