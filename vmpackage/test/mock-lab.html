Exercise 1: Deploy a Virtual Machine

  1. Click on Create a resource to begin.
  2. Select Virtual machine from the list.
  3. Enter the Resource group name (1) and then click Review + create (2).
  4. Click on Deploy.
  5. Click on the Visual Studio Code from the VM desktop.

Note: deployment can take up to 10 minutes to complete.
